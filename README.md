# 🛡️ Hesabat Admin Panel

This project is a dedicated **Admin Application** designed to centrally manage the **"Hesabat"** (Client App) users, approve registration requests, issue special license codes (`HSB-XXXX-XXXX`), and send broadcast notifications.

---

## 🚀 Key Features
* **🔑 Secret Admin Login:** Direct access to the control center using the initial admin password `162142`.
* **🛡️ Special License Code Management:** Generate unique codes tied to each client's name or Gmail address that cannot be used by others (`HSB-XXXX-XXXX`).
* **⭐ VIP & Approval System:** Review client registration requests, send standard approval codes, or grant VIP status directly.
* **📢 Broadcast Notifications:** Send custom notices and reminders to all connected users.

---

## 🔐 Login Method
1. After opening the app, enter **`162142`** as the admin password.
2. Once logged in, you can change the admin password to your own new password if desired.
